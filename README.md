## 🧯 Troubleshooting

<details>
<summary><b>The menu does not open</b></summary>

Run the panel as administrator and confirm the hotkey is not already used by Fortnite or your overlay software. Some builds also block overlay drawing in fullscreen.
</details>

<details>
<summary><b>ESP draws at the wrong position</b></summary>

Position drift usually comes from a resolution or display-scaling mismatch. Set the panel to the same resolution and scaling mode as the game.
</details>

<details>
<summary><b>FPS drops after enabling modules</b></summary>

Turn off skeleton ESP first — it is the heaviest visual module. Limit ESP distance and reduce loot categories to the ones you actually use.
</details>

<details>
<summary><b>Aimbot overshoots targets</b></summary>

Raise smoothing and lower FOV. Both changes reduce how aggressively the crosshair is pulled.
</details>

<details>
<summary><b>Antivirus flags the file</b></summary>

Panels that interact with a running game commonly trigger heuristic warnings. Verify the download source before adding exclusions.
</details>
